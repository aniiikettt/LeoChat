# Chat-Bot

Simple chat-bot project.

## Quick start

1. Create a Python virtual environment and install dependencies:

```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

2. Run the app:

```bash
python main.py
```
